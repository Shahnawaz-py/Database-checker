# Database Checker
A simple *HTML, CSS, and JavaScript* project that checks whether a username and password exist in a predefined database.

## 🌐 Live Demo
Run : https://shahnawaz-py.github.io/Database-checker/

## 📌 About
The Database Checker provides a basic login-style form where users can enter their username and password. JavaScript checks the entered credentials against a predefined user database and displays an alert based on whether the user exists.

## ✨ Features
* Username and password input fields
* Clean and simple UI
* Predefined user database
* Credential verification using JavaScript
* Success and failure alerts
* Responsive layout

## 🛠️ Technologies Used
* *HTML*
* *CSS*
* *JavaScript*
